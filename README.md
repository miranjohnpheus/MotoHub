\# MotoHub



\## A Web-Based Motorcycle Buy-and-Sell Platform with Content Management System



\### Project Description



MotoHub is a web-based platform designed to help users buy, sell, and browse motorcycles online. It provides a convenient way for buyers and sellers to connect through motorcycle listings.



The platform also includes a Content Management System (CMS) that allows motorcycle listings to be managed and updated.



\### Features



\- \*\*Motorcycle Catalog\*\* – Displays available motorcycles with their names, types, prices, and sellers.

\- \*\*Motorcycle Search\*\* – Allows users to search for motorcycles by name or brand.

\- \*\*Sell Motorcycle\*\* – Provides a form for adding new motorcycle listings.

\- \*\*Listing Management\*\* – Allows users to view and delete motorcycle listings.

\- \*\*Dynamic Listing Count\*\* – Automatically updates the total number of available motorcycles.

\### Installation and Usage



1\. Clone or download the MotoHub repository.

2\. Open the project folder.

3\. Open `index.html` in a web browser.

4\. Browse motorcycle listings, search for motorcycles, or add new listings.

All three feature branches were merged into the `main` branch.



\### Project Purpose



MotoHub aims to provide a simple and convenient online marketplace where motorcycle buyers and sellers can connect.



\*\*Note:\*\* This is a demonstration project. Motorcycle listings are stored temporarily in JavaScript and are not connected to a database.
